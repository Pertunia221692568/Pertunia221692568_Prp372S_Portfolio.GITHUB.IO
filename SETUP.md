# 🌸 How to publish this cute portfolio on GitHub Pages

1. Create a new GitHub repository (e.g. `launchpad-agile-portfolio` or `yourusername.github.io`).
2. Upload **everything** inside the `github-portfolio` folder to the root of the repo.
3. Go to **Settings → Pages**.
4. Under “Source”, choose **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`.
5. Save. After 1–2 minutes your portfolio will be live at:
   `https://yourusername.github.io/repo-name/`  
   (or `https://yourusername.github.io` if you used the special username.github.io repo).
